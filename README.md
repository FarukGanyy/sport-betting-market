SportPredictionMarket – Educational Sports Outcome Prediction System
SportPredictionMarket allows users to forecast the results of sports events in a decentralized environment, purely for learning and research on prediction markets.

Core Capabilities
- Create event predictions with possible outcomes
- Users record predictions without monetary stakes
- Trusted oracle verifies final event result
- Transparent scoring and result settlement

Key Functions
create-event, record-prediction, set-result, get-event, get-user-prediction
